# Onze Automation

Automação de testes do **Onze — Organizador de Pelada**.

## Objetivo

Centralizar os testes automatizados externos do produto, cobrindo API e, conforme a aplicação evoluir, fluxos mobile/E2E.

## Branches

- `master`: versão estável
- `development`: integração e validação
- `feature/*`: desenvolvimento por funcionalidade

## P0

Definir a estratégia de automação, preparar CI e criar a base para os primeiros testes da API e do aplicativo.
